# Charming - Belleza Íntima

Aplicación web para gestionar ventas, productos e instalaciones de pago para un negocio de belleza íntima.

## Características

- **Panel de Control**: Visualiza estadísticas generales de tu negocio
- **Gestión de Productos**: Agrega, visualiza y gestiona tu inventario
- **Registro de Ventas**: Registra ventas completas o en cuotas
- **Gestión de Cuotas**: Controla pagos en cuotas y registra abonos
- **Análisis**: Visualiza distribución de ingresos por porcentaje (40%, 30%, 20%, 10%)

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5
- Font Awesome Icons
- LocalStorage para persistencia de datos

## Instalación

1. Clona o descarga el repositorio
2. Abre `index.html` en tu navegador
3. ¡Listo! La aplicación está lista para usar

## Uso

### Agregar Productos
1. Ve a la sección "Productos"
2. Haz clic en "Agregar Producto"
3. Completa los datos del producto
4. Opcionalmente, personaliza la categoría
5. Haz clic en "Guardar Producto"

### Registrar Ventas
1. Ve a la sección "Ventas" o haz clic en "Vender Producto" desde el panel
2. Selecciona los productos a vender
3. Ingresa cantidades y precios
4. Elige tipo de pago (Completo o Cuotas)
5. Ingresa nombre del cliente
6. Haz clic en "Completar Venta"

### Gestionar Cuotas
1. Ve a la sección "Cuotas"
2. Visualiza todas las cuotas pendientes
3. Haz clic en "Registrar Pago" para abonar a una cuota
4. Ingresa el monto a pagar

### Ver Análisis
1. Ve a la sección "Análisis"
2. Visualiza la distribución de ingresos por porcentaje
3. Tabla detallada de todas las ventas con desglose

## Almacenamiento

Todos los datos se guardan en el navegador usando LocalStorage. Los datos persisten entre sesiones.

## Características de Diseño

- Interfaz responsiva (funciona en desktop, tablet y móvil)
- Sidebar navegable
- Modales para agregar/editar datos
- Tablas paginadas
- Estadísticas en tiempo real
- Diseño moderno con gradientes

## Notas

- Los datos se guardan localmente en el navegador
- Si limpias el caché del navegador, los datos se perderán
- Se recomienda hacer backups periódicos exportando los datos
